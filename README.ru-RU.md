## Зачем нужен Pi-Harness?

Pi-Harness переносит Pi Coding Agent в настольную рабочую область для macOS, Windows и Linux. Управляйте разговорами, проектами, файлами, Git, моделями и Skills в одном месте, проверяйте запуски, задавайте бюджеты, восстанавливайте работу и координируйте команды агентов.

Агентов запускает Native Pi. Сессии, конфигурация, инструменты, Skills и расширения сохраняют совместимость с Pi; им можно пользоваться и вне настольного приложения.

## Возможности

### Рабочая область, файлы и Git

Начните отдельный чат или откройте проект и продолжите сессию Pi. Просматривайте потоковые ответы, рассуждения, вызовы инструментов, изображения и изменения файлов; выбирайте модель, уровень рассуждений и инструменты, сжимайте контекст разговора. Инструменты рабочей области открывают Harness и агентов, сохраняя разговор и неотправленный черновик.

Доступны поиск и просмотр файлов, предпросмотр медиа и документов, лёгкий текстовый редактор с подсветкой синтаксиса, номерами строк, поиском, отменой/повтором, явным сохранением и защитой от конфликтов внешних изменений. Git предлагает различия, историю, графики активности, коммиты, необязательную генерацию сообщений коммитов с ИИ и worktree.

### Провайдеры и модели

Настройте совместимые с Pi провайдеры по шаблонам или собственным адресам, управляйте данными доступа, получайте список моделей там, где это поддерживается, проверяйте подключение и выбирайте модель чата. Поддерживаемые модели изображений позволяют создавать и редактировать изображения, а затем скачивать результат.

### Skills, расширения, пакеты и MCP

В центре возможностей просматривайте и редактируйте встроенные и локальные Skills, управляйте пакетами и расширениями Pi. Введите `@` в поле сообщения для поиска и вызова установленного Skill. Подключайте MCP через поддерживаемые пакеты. Дополнения [Superpowers](https://github.com/obra/superpowers) и [Odai](https://github.com/orziz/odai) можно устанавливать, обновлять и удалять по своему выбору.

### Harness: наблюдение, управление и восстановление

Просматривайте Runs, Trace, Replay, временную шкалу и действия инструментов. Сравнивайте запуски, отслеживайте ветвления и повторы в Run Tree, проверяйте токены, стоимость, длительность, артефакты и статистику проекта.

Задавайте политики инструментов и бюджеты запусков, создавайте контрольные точки, продолжайте, ветвите и повторяйте работу. Оценка, диагностика и базовые запуски для проверки регрессий помогают проверять результаты и находить причины сбоев по записанным данным.

### Команды агентов и координация задач

Координируйте агентов Pi с помощью повторно используемых команд и шаблонов. Назначайте зависимости, приоритеты и исполнителей, запускайте задачи вручную, последовательно или параллельно, передавайте результаты и артефакты, применяйте этапы проверки. Worktree разделяют изменения агентов; бюджеты, подсказки о конфликтах, пауза, продолжение, остановка, повтор, пропуск и переназначение помогают управлять работой.

### Локальная история разговоров

Просматривайте историю Claude Code, Codex (включая настольное приложение и архив), Cursor, Cursor Agent, Gemini CLI, OpenCode и Pi вместе. Доступны поиск, фильтры по источнику, проекту и датам, а также собственные папки истории.

Исходный разговор доступен только для чтения. Проверьте передачу задачи и отредактируйте следующую инструкцию, затем продолжите в новом чате Pi в том же проекте. Просмотр, локальный предпросмотр и повторное сканирование не расходуют токены модели. Необязательная сводка с ИИ использует настроенную модель только по запросу.

### Архитектура проекта

Откройте Architecture в рабочей области для просмотра модулей, зависимостей, точек входа и ссылок на исходный код. Фильтруйте пакеты, выделяйте модуль, переключайте страницы карты, меняйте масштаб и включайте полный экран. Сохраняйте снимки анализа, проверяйте уведомления об изменениях исходников и экспортируйте JSON, автономный HTML или текущий вид в PNG.

Локальный анализ не расходует токены модели; описания ИИ необязательны. Связи импортов JavaScript, TypeScript и Vue анализируются локально, для других поддерживаемых языков доступен файловый индекс. Область охвата и ограничения анализа указаны явно.

### Темы и собственное оформление

Выбирайте классические палитры, Ming, Starship Cockpit, фоны macOS 27 или импортированное оформление. Новые установки используют тёмную тему. Настраивайте имена в чате, значок приложения, локальный фон, свечение окна и экрана, эффект пламени в поле ввода. Проверка среды сопровождается стартовой анимацией; версия без маскота сохраняет общие настройки оформления.

### Среда и настройки приложения

Проверяйте Node.js, npm, PATH, Pi Coding Agent и текущую конфигурацию. В поддерживаемых средах устанавливайте, обновляйте и восстанавливайте Pi; используйте диагностику, резервные копии конфигурации и проверку обновлений приложения. Интерфейс доступен на восьми языках.

## Создайте собственное оформление

Используйте [шаблон оформления Pi-Harness](https://github.com/wangmiaozero/pi-harness-skin-starter) для создания нужного стиля.

1. Используйте репозиторий как шаблон или скачайте его.
2. Откройте его с агентом для программирования и опишите стиль в готовом запросе.
3. Импортируйте результат через **Настройки → Тема → Импортировать тему**.

Многоязычный шаблон содержит рекомендации по цветам, превью, фону и необязательному изображению персонажа. Обновляйте и распространяйте оформление в отдельном репозитории.

## Скачать

Скачайте опубликованный установщик на [GitHub Releases](https://github.com/wangmiaozero/pi-harness/releases), выбрав файл для своей платформы.

| Платформа           | Установщик                  |
| ------------------- | --------------------------- |
| macOS Apple Silicon | `.dmg` · `arm64`            |
| macOS Intel         | `.dmg` · `x64`              |
| Windows x64         | `.exe` · Установщик Windows |
| Linux x64           | `.AppImage`                 |

Пользователям готового приложения не нужно клонировать репозиторий или устанавливать pnpm. В поддерживаемых средах приложение помогает установить Pi и настроить его окружение.

> Сборки сообщества для macOS могут быть не подписаны. Если первый запуск заблокирован, используйте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.

## Начало работы

1. Запустите Pi-Harness и проверьте среду на странице обзора.
2. Настройте провайдера, проверьте подключение и выберите модель.
3. Начните отдельный чат или откройте проект.
4. Начните или продолжите сессию Pi и работайте с разговорами, файлами и Git.
5. Для управления запусками и командами откройте инструменты рабочей области.

## Требования

Приложение поддерживает macOS Apple Silicon, macOS Intel, Windows x64 и Linux x64. В поддерживаемых средах Pi Coding Agent можно установить или восстановить из приложения. Для запуска из исходников нужны Node.js ≥ 22.22.2 и pnpm 9.12.1.
