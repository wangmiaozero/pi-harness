# Installation and update troubleshooting

| Problem                       | What to do                                                                                                                                           |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Checksum mismatch             | Stop. Download again from the official Releases page; do not run the mismatched file.                                                                |
| macOS security warning        | Confirm the official source and checksum. Use the operating system's per-app confirmation only if you trust the download; do not disable Gatekeeper. |
| Windows SmartScreen warning   | Community installers are unsigned. Confirm the source and checksum before deciding whether to proceed; do not disable Defender.                      |
| Linux AppImage does not start | Make the exact downloaded file executable, then launch it. Check your distribution's AppImage requirements.                                          |
| Update opens a download page  | Expected for Community builds. Download and install the matching architecture and variant manually.                                                  |
| Installation fails            | Quit the app, preserve your application data and report your OS, architecture, app version and the visible error. Never include credentials.         |

Downloads: [official Releases](https://github.com/wangmiaozero/pi-harness/releases).
See [Community Release](community-release.md) and [updates](update-strategy.md).
