# 轻量代码编辑器约定

## 定位

Pi-Harness 的文件区域只提供轻量代码编辑能力，用于查看和快速修改项目文件。它不是通用 IDE，也不承担项目构建、运行、调试或语言服务职责。

## 支持范围

- 所有可安全读取的文本文件均可编辑；无法识别的扩展名使用纯文本模式。
- 通过 CodeMirror 语言目录按需加载语法高亮，覆盖常见编程语言、标记语言和前端框架文件。
- 提供行号、选择、查找、撤销/重做、`Cmd/Ctrl+S`、显式保存按钮和未保存状态标记。
- 文件切换时，未保存内容保留在当前进程的内存缓冲区中。
- 保存前校验打开文件时的 SHA-256 内容版本。磁盘内容被外部修改时，默认拒绝写入，并由用户明确确认是否覆盖。
- 写入仅允许已授权项目根目录内的现有普通文件；拒绝符号链接、二进制文件和超限内容。
- 超过 256 KiB 的文本只做截断只读预览；图片、音频、PDF、DOCX 和其他二进制文件保持预览或只读状态。

## 明确不做

- LSP、IntelliSense、语义补全、实时诊断、符号索引、跳转、重构。
- 调试器、断点、任务系统、构建/运行入口、集成终端。
- VS Code / JetBrains 插件兼容层或独立 IDE 插件体系。
- 针对具体语言或框架的工程管理、依赖管理、生成器和脚手架。

## 实现约束

- 编辑器 UI、内存缓冲区和文件写入 IPC 必须与 Agent 执行链路解耦。
- 渲染进程不能直接访问文件系统；读取和写入统一经过 preload 暴露的类型化 IPC。
- 写入必须同时通过项目根目录授权、普通文件校验、大小限制、二进制检测和内容版本冲突检测。
- 新增编辑器能力若超出“支持范围”，必须先修改本约定并作为独立产品决策评审，不能随其他需求顺带引入。
- 不持久化未保存文件内容，避免将项目源码写入应用设置或浏览器存储。
